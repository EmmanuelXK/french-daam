# French Daam - International Draughts

Mobile-friendly web app for French Daam (International Draughts, 10×10).

## Features
- Dark brownish UI (Lichess-inspired board)
- Fully responsive / mobile-friendly
- Play vs Bot (no time limit)
- Rapid & Blitz timed modes
- Local 2-player (same device)
- Mandatory capture + majority rule
- Flying kings
- Undo, new game, clocks

## How to play
Open `index.html` in any modern mobile or desktop browser.

## Rules (French / International Draughts)
- 10×10 board, dark squares only
- 20 pieces each
- Men move forward one, capture forward & backward
- Capture is mandatory; must take maximum pieces
- Kings fly any distance on diagonals
- Promote only when move ends on last rank
